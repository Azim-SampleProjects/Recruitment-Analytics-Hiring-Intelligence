# Recruitment Analytics & Hiring Intelligence

### Project Overview

An end-to-end Recruitment and People Analytics project using **Python, Pandas, Plotly and statistical analysis** to evaluate recruitment performance, candidate experience, sourcing effectiveness and offer acceptance.

The project uses six interconnected synthetic recruitment datasets to demonstrate data validation, exploratory analysis, statistical testing and business decision-making.

### Dataset

- **15,000** applications
- **9,000** candidates
- **2,000** job postings
- **320** companies
- **7,196** interview records
- **938** offers

*Source: Synthetic recruitment dataset. Findings are illustrative and do not represent actual hiring-market outcomes.*

### Business Analysis

Six recruitment questions were investigated:

1. Recruitment funnel effectiveness
2. Recruitment source effectiveness
3. Hiring difficulty by job type
4. Recruitment process efficiency
5. Candidate experience and selection outcomes
6. Salary position and offer acceptance

### Statistical Analysis

| Investigation | Method | Key Result |
|---|---|---|
| H1 — Recruitment Source | Chi-square, Cramér's V | No significant association (p = 0.5163) |
| H2 — Candidate Experience | Welch's t-test, Cohen's d | No significant mean difference (p = 0.2716) |
| H3 — Salary Position | Logistic regression | No significant adjusted association (p = 0.4590) |

The findings reinforce the importance of evaluating recruitment outcomes using multiple performance indicators rather than relying on individual metrics.
